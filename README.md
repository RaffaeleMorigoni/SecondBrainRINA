# SecondBrain — RINA

Materiale di lavoro sul progetto RINA (agente Copilot Studio su Dynamics 365 F&O, UAT).

## Struttura

- `plans/` — analisi, stati UAT, messaggi, guide di rilascio (prefisso data `AAAAMMGG_`)
- `plans/backup/` — copie delle istruzioni di padre e figlio prima di ogni modifica, con i rollback
- `plans/prove_uat/` — screenshot delle prove in F&O e nel pannello di test

Il materiale Anticimex vive in `SecondBrainANT`.
